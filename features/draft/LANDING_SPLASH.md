# Feature: Landing Splash Page

## Description

At the top of the landing page of the website, the visitor should be greeted with a design-industry styled "splash art" banner.

The component needs to be captivating and designed in a way that it draws in the user's curiosity.

## Requirements (Informally ig, it's kinda hard to write UI requirements in TEXT)

- Placement: The "Intro Message" should be placed on the left side and the profile photo (use a placeholder) should be on the right
- Spacing: The content should be spaced apart enough to ensure that the components don't look "squished together"
- Animations: Content should be "animated in" to the scene, for now, let's try a fade-in effect from their corresponding sides
- Navigation: The landing page is designed to be a lengthy vertical scroll. Add a button to allow the user to be auto-scrolled to the next section below
- Styling: Colors should follow the palette given in `index.css`
